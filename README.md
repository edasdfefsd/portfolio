# Hi, I'm building the layer where AI meets real machines.

Mechanical engineering student in Hong Kong, heading toward industrial
engineering and automation. My interest is not in models on a screen — it is in
what happens when a model has to touch a motor, a sensor, or a production line.

## What I'm working on

- **A 3-step agent workflow for one repetitive shop-floor task.** Goal: a person
  hands it a task, it comes back with a usable result, and someone pays for it.
  Status: building. Numbers will be published when they exist.
- **An Arduino line-follower car.** Hardware and PID tuning. Tuning notes and
  failure modes go here once written up properly.
- **Notes on factory automation.** Datasheets I read, things that broke, numbers
  that surprised me.

## How I work

Small, verifiable loops. One working step beats ten planned systems. If a number
was not measured, it does not go in the README.
